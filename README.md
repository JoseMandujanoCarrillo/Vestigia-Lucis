# Vestigia Lucis Frontend

Aplicación React/Vite para Vestigia Lucis.

## Vercel

- Framework: Vite
- Build: `npm run build`
- Output: `dist`

La API de producción ya está configurada en `.env.production`. Vercel la incluirá al compilar.

La casilla de publicación aparece marcada por defecto; el administrador puede desmarcarla para guardar como borrador. Se permiten de una a tres imágenes usando las columnas existentes. En una base Neon ya creada, actualiza la restricción de publicación con el SQL de migración correspondiente; no se agregan columnas.
